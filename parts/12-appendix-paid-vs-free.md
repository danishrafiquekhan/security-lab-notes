**Part 12: Appendix — Paid vs. Free Summary Table**<!--h1-->

A single reference table for every tool/service/product mentioned across
this document, covering what's actually free, what the real limits of a
free tier are, and what role each one plays in this specific lab. Tiers
and limits below reflect general public vendor documentation as of this
writing (2026) — vendors change pricing and free-tier limits over time,
so treat specific numbers as "accurate as of when this was written,"
not permanent facts, and re-verify before relying on them for a real
budget decision.

| Tool / Service | Free tier or fully free? | What the paid tier adds / real limit of the free tier | Used in this lab as |
|---|---|---|---|
| **Wazuh** | Fully free (Apache 2.0, self-hosted, no paid tier at all for the core product) | No feature gating — Wazuh's business model is paid support/services on top of a genuinely free product, not a crippled free tier. Real "cost" is self-hosting/ops effort (you run and maintain the containers/indexer yourself). | Core SIEM/XDR for the lab — manager, indexer, dashboard containers; ingests MySQL and Cloudflare Pages traffic logs. |
| **TheHive** | Free (community edition, self-hosted) | TheHive 5's commercial "Strategic Blue"/enterprise offerings add SSO, multi-tenancy and support contracts beyond the community edition; the community edition used here is fully functional for case management on its own. | SOAR/case management — now actually wired to Wazuh via the `custom-thehive` integration, filtered by rule group, verified creating real cases from Cloudflare, MySQL, and Suricata alerts; the stack itself still sits stopped by default (16GB Docker resource constraint), brought up on demand. |
| **Cortex** | Free (self-hosted, paired with TheHive) | Individual analyzers may themselves call paid third-party services (e.g. a paid threat-intel API) — Cortex itself is free; some analyzers it runs are only as free as the service they call. | Analyzer/responder engine for TheHive; stopped by default alongside TheHive, brought up on demand. |
| **Cassandra** | Fully free (Apache 2.0) | No paid tier — DataStax sells a managed/commercial offering built on Cassandra, but the open-source database itself is free. | Backing datastore for TheHive. |
| **Elasticsearch** | Free (Apache 2.0 as of recent versions / prior Elastic license depending on version) | Elastic's commercial tiers (via Elastic Cloud or the platinum/enterprise self-managed subscriptions) add features like advanced security, ML, and support — not required for TheHive's use here. | Backing search/index store for TheHive. |
| **LocalStack** | Freemium — community edition is free | Free (community) edition covers core services (IAM, S3, Lambda, and more) used for this lab's testing; the paid Pro tier adds broader AWS service coverage and persistent state across restarts. | Local AWS emulation for `aws-identity-detection`'s IAM privesc detection testing; built previously, stopped/idle this session. |
| **Suricata** | Fully free (open source, GPLv2) | No paid tier for the engine itself — commercial vendors sell managed rule feeds/support around it. | Network IDS (`jasonish/suricata:latest`), now fixed and wired to Wazuh — a real ET ruleset alert (sid 2036252) verified firing through Wazuh's built-in Suricata decoder/rule, on a dedicated Docker bridge network built to work around Docker Desktop for macOS's lack of real host-interface access. |
| **MySQL** | Freemium — Community Edition is free | Community Edition (used here) is fully free and fully functional; Oracle's paid Enterprise Edition adds features like advanced auditing, encryption add-ons, and support contracts, none needed for this lab's use as a monitored target. | The `soc-lab-mysql` container — a real, deliberately attacked, logged target feeding Wazuh via a relay script. |
| **Cloudflare Pages** | Freemium | Static hosting itself is free with generous limits (unlimited static requests, a monthly build-minutes allowance); Logpush/continuous log retention specifically requires a paid Cloudflare plan — which is exactly why this lab captures live traffic via `wrangler ... tail` instead. | Hosts the real public `soc-lab-target.pages.dev` synthetic lab site, plus its `_middleware.js` request-logging Function. |
| **Cloudflare Workers** | Freemium | Free tier includes a substantial daily request allowance for Workers; higher volume, longer CPU time per invocation, and some advanced features (e.g. Durable Objects at scale) require a paid plan. | Referenced as the underlying platform Cloudflare Pages Functions run on (the `_middleware.js` logging function is a Pages Function, which runs on the Workers runtime). |
| **Cloudflare Logpush** | Paid only — no free-tier access | Requires a paid Cloudflare plan; this is precisely the gap that makes `wrangler tail` necessary in this lab instead of continuous native log streaming. | Not used in this lab — explicitly worked around due to being unavailable on the free tier. |
| **Cloudflare R2** | Freemium | Free tier includes a monthly storage and operations allowance with **zero egress fees** (R2's headline differentiator vs. S3); usage beyond the free allowance is billed. | Mentioned only as the scope of this session's earlier, wrong-for-Pages API token (R2-storage-scoped, not Pages-scoped) — see Part 10.3. |
| **Docker Desktop** | Freemium | Free for personal use, education, small business, and non-commercial open-source use; larger commercial organizations (above a headcount/revenue threshold) require a paid subscription. | Container runtime for the entire locally-running stack — Wazuh, TheHive/Cortex, LocalStack, Suricata, MySQL. |
| **QEMU** | Fully free (open source, GPL) | No paid tier — a free, general-purpose machine emulator/virtualizer. | Runs the Windows Server 2022 Evaluation VM directly via raw `qemu-system-x86_64`/`qemu-img` commands. |
| **QuartzVM** | Fully free (MIT-licensed, open source) | No paid tier — a free desktop GUI wrapper around QEMU the user built themselves. | Available as an optional GUI for managing QEMU VMs; the Windows Server VM in this lab was actually built via raw QEMU commands, not through QuartzVM's GUI. |
| **Terraform (CLI)** | Fully free (Mozilla Public License 2.0) | The open-source CLI itself has no paid tier or feature gate — it runs and manages state entirely locally/against whatever backend you configure, for free. | The IaC tool used across all `terraform-labs` exercises (01–07). |
| **Terraform Cloud** | Freemium | Free tier covers a limited number of users and includes remote state management and remote runs; paid tiers add features like Sentinel policy-as-code enforcement, SSO, and higher usage limits. | Integration target of `terraform-labs` exercise 04 specifically — distinct from the free CLI used in every other exercise. |
| **Azure** | Freemium | A free-tier subscription includes a limited credit amount plus a set of always-free service allowances for the first 12 months and beyond; real usage beyond those allowances is billed — which is exactly why this lab's Azure README documents a spending cap set before creating anything. | The target cloud for all `terraform-labs` exercises; a free-tier subscription exists, but no exercise has actually been `apply`'d against it. |
| **Microsoft Sentinel** | Paid (consumption-based) | Billed per GB of data ingested/analyzed and per analytics rule run — no standing free tier for real production use, though a trial tenant with some allowance can be obtained via the M365 Developer Program. This is the explicit, stated reason Wazuh was chosen for the actual live lab instead. | Not deployed anywhere in this lab — the *target* schema/query language (`SigninLogs`, `AuditLogs` KQL) that `detection-engineering`'s Sentinel-facing content and `sentinel-soar-playbooks`' Logic App *designs* are written for, without ever having a real tenant to deploy them into. |
| **Microsoft Graph API** | Freemium (access tier depends on the tenant/licensing behind it) | The API itself has no separate price — what's billed (or not) is the underlying Microsoft 365/Entra ID tenant and license tier behind the identity/data it's querying; a developer tenant (see M365 Developer Program) provides free access for this kind of scripting/testing work. | Used by the private `intune-endpoint-health-platform` repo's IAM scripts (privileged role access review, orphaned account detection) and referenced as the mechanism behind the Sentinel playbook designs' account-disable/session-revoke actions. |
| **M365 Developer Program (E5 trial)** | Free | Provides a free, renewable sandbox Microsoft 365 E5 tenant (typically on a 90-day renewable cycle, subject to Microsoft's current program terms) intended for development/testing, not production use — a real but time-boxed and non-production-grade free tier. | The realistic free path to a Sentinel-adjacent/Entra ID trial tenant referenced above; not confirmed as actually set up and exercised end-to-end in this lab. |
| **Auth0** | Freemium (Okta-owned) — actually in use on a **free trial tier**, time-boxed on a countdown rather than an indefinite free allowance | Free tier covers a meaningful number of monthly active users/logins for development and small projects; paid tiers add enterprise features (advanced MFA policies, custom domains at higher tiers, SSO connections beyond the free allowance, System Log retention length). | Now a real, working fourth live source for this lab — a real Machine-to-Machine app (Domain/Client ID/Client Secret) was created and authorized, its over-broad default Management API scope narrowed and verified, and its System Log checkpoint-polled into Wazuh via custom rules. No longer a planned/open gap. |
| **Okta Developer Edition** | Free | Free developer tier intended for building/testing integrations, with usage caps appropriate to development rather than production traffic. | Discussed as an alternative identity provider option early on, not pursued — Auth0 was chosen instead and has since actually been finished (see above). |
| **GitHub** | Freemium | Free tier includes unlimited public repositories and (with reasonable limits) private repositories, free CI minutes on a monthly allowance, and core collaboration features; paid tiers add more CI minutes, advanced security features (e.g. certain code-scanning capabilities), and organization-level administrative controls. | Hosts every repo in this lab's portfolio — all public repos are free-tier public repos; `intune-endpoint-health-platform` is a private repo, also within the free tier's private-repo allowance. |
| **Windows Server 2022 Evaluation** | Free, but explicitly **not** a real production license | The evaluation build is time-limited — Microsoft's Server evaluation media is generally documented as a **180-day** evaluation period (this document notes 180 days as the commonly cited figure; the brief for this lab did not itself specify a number, so treat this as accurate-to-general-Microsoft-documentation rather than lab-verified — confirm against the actual installed build's `slmgr /dlv` output if the exact remaining evaluation window ever matters operationally). After the evaluation period, the OS requires conversion to a licensed edition or will begin forcing periodic shutdowns. | The Windows Server 2022 VM built via raw QEMU in this lab, intended to eventually run Sysmon + a Wazuh agent + Atomic Red Team tests — evaluation-licensed, not production-licensed, by design (it's a disposable-in-principle lab VM, though see Part 9's note on the tension between that and its current hardcoded-password/10-boot-autologon configuration). |

**Notes on accuracy and drift**<!--h2-->

Free-tier limits, evaluation license durations, and pricing structures
are exactly the kind of detail vendors change without much notice. The
figures above reflect this document's best understanding at time of
writing and, where the underlying lab material didn't specify an exact
number itself (the Windows Server evaluation period, specifically), that
uncertainty is stated plainly rather than presented as a confirmed lab
fact. Before making a real budget or licensing decision based on any row
in this table, re-check the vendor's current published terms directly —
this table is a study aid and lab reference, not a procurement source of
truth.
